Verwendung auf eigene Gefahr

Dieses unabhängige Werkzeug wird ohne Gewähr bereitgestellt. Fehler oder unterbrochene Restores können zu Datenverlust oder nicht mehr erreichbaren Passwörtern führen. Bewahre vor jedem Restore eine separate, unveränderte Sicherung auf und prüfe das Ergebnis auf deinem Ledger.

Einträge im Stapel ergänzen

Ein Nickname pro Zeile. Exakt 1–19 druckbare ASCII-Zeichen; Leerzeichen bleiben erhalten. Keine echten Passwörter eingeben.

Maximal 19 Zeichen pro Zeile. Ab Zeichen 20 wird rot markiert.

Gelöschte Originalnamen können erneut hinzugefügt werden. Gleiche Einstellungen stellen den Eintrag wieder her; geänderte Einstellungen erzeugen ein anderes Passwort und erfordern eine Bestätigung.

Länge 4 und 6: nur Ziffern. Die Generation bestimmt den Ableitungsalgorithmus und darf bei bestehenden Einträgen nicht geändert werden.

GERÄTEVERBINDUNG

Dein Ledger

Ledger per USB verbinden, entsperren und die Passwords-App öffnen. Ledger Live und andere Ledger-Tabs schließen.

Browser-Unterstützung

Chrome und Edge am Computer unterstützen WebUSB. Chrome auf Android unterstützt die API ebenfalls; USB-Host/OTG, Kabel und Ledger müssen zusammen funktionieren. Safari und Firefox unterstützen WebUSB derzeit nicht. Ein anderer Browsername auf iPhone/iPad allein macht USB nicht verfügbar.

MDN · WebUSB

Backup und Restore erfordern deine Bestätigung auf dem Gerät. Ein Restore ersetzt die vollständige Nickname-Liste.

Keine Seed-Phrase. Keine privaten Schlüssel. Keine externen Bibliotheken oder Netzwerkaufrufe.

Offline-Dateibearbeitung funktioniert direkt per Doppelklick. Für USB Chrome/Edge verwenden; falls nötig über localhost oder eigenes HTTPS-Hosting öffnen.

Unabhängiges Werkzeug, kein offizielles Ledger-Produkt. Formatprüfung basiert auf LedgerHQ/app-passwords, Commit bf2319b8. Die Datei enthält Nicknames und Ableitungsparameter, keine Passwörter. Ein SHA-256-Fingerabdruck erkennt Dateiveränderungen beim Vergleich; das Ledger-Format enthält keine Signatur oder Prüfsumme.
